# Inclusive Onboarding Backend

Backend REST APIs for the ALX Accessible Onboarding Hackathon.

## Quick Start
1. `npm install`
2. Create a `.env` file with `PORT=4000` and `MONGODB_URI=your_mongodb_string`
3. `node seed.js` (to populate test jobs)
4. `npm run dev`

## API Documentation
Once the server is running, view the interactive Swagger UI at:
**http://localhost:4000/docs**
